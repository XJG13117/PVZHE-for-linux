## **在ubuntu24版系统下，只需：**

先运行

`tar -xzf pvzhybrid-linux-20261004.tar.gz`

解压

`cd pvzhybrid-linux`

`./play-pvz.sh --check`

运行一次即可

后续可在桌面启动

## 如何更新

找到解压缩后的ext3文件夹

里面是类似于发布的window版文件夹

进到能找到PCK文件的地方

例如：植物大战僵尸杂交版发布版0.29.0.Csharp.pck

将里面所看到文件全部删除

将潜艇伟伟迷发布的更新包（包含PCK文件）全部放到这里就行
